# Pit Wall: F1 Garage Challenge

A terminal-based Python adventure game where you are the race engineer for a fictional Formula 1 team, preparing the car shortly before qualifying.

## About the game

Start in the Main Garage hub and visit the Tyre Room, Simulator, Telemetry Room, and Pit Wall. Earn preparation points with correct engineering calls (tyre compound, aero setup, lap-data analysis), then head to the Qualifying Grid for a final strategy decision and a fictional qualifying result.

## How to run

```bash
python pit_wall.py
```

## Technologies used

- Python 3 (standard library only: `random`, `time`)
- Terminal / command-line input and output
